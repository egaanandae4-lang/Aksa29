# Portofolio Pribadi (HTML, CSS, JavaScript)

Template website portofolio pribadi yang responsif dengan fitur pengganti tema **Pastel (Mode Terang)** dan **Cyberpunk (Mode Gelap)**.

## Fitur Utama
- **Dual Tema (Pastel & Cyberpunk):** Tombol ganti tema otomatis menyimpan preferensi di `localStorage`.
- **Galeri Interaktif:** Dilengkapi filter kategori (*Semua, Web, Desain, Fotografi*) dan *Lightbox Modal*.
- **Formulir Kontak:** Dilengkapi validasi input bawaan JavaScript.
- **Responsif:** Tampilan rapi di desktop maupun ponsel.

## Cara Upload & Deploy ke GitHub Pages
1. Ekstrak semua file (`index.html`, `style.css`, `script.js`, `README.md`) ke dalam satu folder.
2. Buat repositori baru di [GitHub](https://github.com/new) (misalnya `portofolio-pribadi`).
3. Upload semua file tersebut ke repositori.
4. Masuk ke menu **Settings** > **Pages** di repositori GitHub kamu.
5. Pada bagian **Branch**, pilih `main` lalu klik **Save**. Tunggu 1–2 menit hingga link website aktif!
